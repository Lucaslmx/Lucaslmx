Página web para apresentar o perfil, os estudos e projetos de Lucas Melo. O site também inclui uma seção de habilidades com um efeito de interação nos cartões.

O código executável está disponível em [`index.html`](index.html).

## 🎯 Objetivo

Desenvolver e personalizar um portfólio usando HTML, CSS e Bootstrap, organizando as informações em seções e praticando navegação, layout responsivo e componentes interativos.

## 🧠 Conceitos utilizados

- Estrutura de documento HTML e metadados para dispositivos móveis.
- Tags semânticas `header`, `main`, `section`, `nav` e `footer`.
- Links internos para navegação entre seções.
- Listas para organizar os itens do menu.
- Classes do Bootstrap para grid responsivo, espaçamento, cards e botões.
- Navbar recolhível e carousel do Bootstrap.
- CSS em `<style>`, variáveis em `:root` e comentários em português.
- Transições e seletor `:hover` para movimentar os cartões da seção de habilidades.

## ▶️ Como executar

É necessário ter Git e um navegador web. Clone o repositório na branch da atividade e abra o arquivo `index.html`:

```bash
git clone --branch Ag15_DS_I https://github.com/Lucaslmx/Lucaslmx.git
cd Lucaslmx
```

Abra `index.html` no navegador. O Bootstrap é carregado pela internet; por isso, os componentes visuais precisam de conexão para carregar seus estilos e scripts.
