Aplicação desenvolvida durante os estudos do curso [JStack](https://github.com/jstack-edu), de [Mateus Silva](https://github.com/maateusilva).

O projeto explora desenvolvimento web, organização de aplicações e integração entre diferentes camadas de uma solução.

- [MyContacts Frontend](https://github.com/Lucaslmx/MyContacts-Frontend)
- [MyContacts API](https://github.com/Lucaslmx/MyContacts-API)

Projeto baseado em otimizações e adaptações para execução em ambientes Linux utilizando Raspberry Pi.
